# Flujo de caja y ventas — endurecimiento

## Regla operativa

Una venta completada con pago en efectivo aumenta el efectivo esperado de la sesión. Una cancelación o devolución autorizada de esa venta reduce el efectivo esperado por el efectivo que fue recibido y posteriormente revertido.

## Flujo

Apertura de caja → venta/cobro → preparación/entrega → cancelación o devolución autorizada cuando aplique → cierre de caja → conciliación → auditoría.

El cierre debe distinguir ventas en efectivo de pagos no monetarios y considerar las reversiones de efectivo para que la conciliación no quede inflada después de una devolución o cancelación.
